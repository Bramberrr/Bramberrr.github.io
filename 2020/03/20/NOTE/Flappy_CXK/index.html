Flappy Cai Xukun: A C++ Course Project

Created2020-03-20
|Post View:

About this project

This was my final project for a C++ programming course at Zhejiang University: a small side-scrolling game called Flappy Cai Xukun, written in C++ with the EasyX graphics library in Visual C++ 6.0.

The game was made because of the singer and idol Cai Xukun. In 2019 he was everywhere on the Chinese internet, and a handful of his catchphrases and moments became memes: introducing himself as a trainee who likes “singing, dancing, rap and basketball”, a dribbling clip from his NBA ambassador promo, and a line from his song Just Because You Are Too Beautiful, whose title sounds like “chicken, you’re too beautiful” in Chinese, which is why chickens show up in the game. When we had to build a game for the course, a game starring him playing basketball and rapping was the obvious choice. The code and assets are on GitHub: Bramberrr/flappycxk.

How the game works

The player character stands on a rainbow bridge in front of a scrolling starfield. Basketballs, chickens and, later, floating comments (the “danmaku” that fly across Bilibili videos) scroll in from the right, and each one has to be handled differently:

Object What to do Result
Basketball Hold ↓ to get ready to catch it +5 points
Comment (appears after 100 points) Hold → to rap back at it +10 points, or −20 points and a lost life if you miss
Chicken Hold ↑ to jump over it Lose a life if it hits you

You start with 3 lives and get one back (up to 3) every 100 points. The other controls:

  • ← makes him stop and introduce himself, pausing the game for 6 seconds while the audio plays.
  • Shift saves a screenshot; Ctrl and Alt turn the background music off and on.
  • Esc goes back to the difficulty menu.

There are three speeds (normal, fast and very fast), set by the delay between frames: 80, 60 or 40 ms. When you run out of lives, the game shows a “you have received a lawyer’s letter” game-over screen (another meme from the time) and writes your score to record.txt.

How the code is organized

The project is small, with three source files:

  • ikun.cpp is the entry point: it starts the music and opens the menu.
  • cxk.cpp has the game itself: the menus, the main loop, drawing, input, collisions and the starfield.
  • media.cpp plays the music and sound clips with the Windows mciSendString API, and saves screenshots.

The menus are images with clickable regions, read from EasyX mouse messages. The game loop runs at a fixed delay and does the same steps every frame:

The objects on screen are kept in a linked list. New ones are added at the tail, with a 1-in-5 chance each frame, but only if the previous one is far enough away; objects that scroll off the left edge are removed:

A few small touches I was proud of at the time: the character is animated from a six-frame dribbling sequence, basketballs bob up and down randomly as they fly in, the rainbow bridge is drawn line by line by stepping the hue, and each star scrolls at its own speed, with faster stars drawn brighter for a sense of depth:

Looking back

It’s a very “first big C++ project” codebase: everything lives in global state and one big loop, input is polled with GetAsyncKeyState, objects are managed with malloc/free by hand, and the audio clips can pause the whole game. But it was a fun way to learn how a game loop, sprite animation, collision checks and a linked list fit together, and it definitely made the course demo memorable.
